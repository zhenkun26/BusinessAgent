# 财务报销制度

## 1. 报销流程

### 1.1 标准流程
1. 员工填写《费用报销单》
2. 直属主管审批(2 个工作日内)
3. 财务部审核(3 个工作日内)
4. 出纳打款(2 个工作日内)

### 1.2 紧急报销
- 紧急报销需附加说明,可跳过主管审批,直接由财务总监审批
- 紧急报销限每月 1 次

## 2. 报销类型与限额

### 2.1 差旅费
| 项目 | 标准(每日) | 备注 |
| :-- | :-- | :-- |
| 交通费 | 实报实销 | 高铁二等座 / 经济舱 |
| 住宿费 | 500 元 | 一线城市 800 元 |
| 餐补 | 100 元 | 不需发票 |
| 市内交通 | 80 元 | 出租车 + 网约车 |

### 2.2 招待费
- 单次 ≤ 1000 元:主管审批
- 单次 1000-3000 元:部门负责人审批
- 单次 ≥ 3000 元:总经理审批
- 招待费需附《招待申请单》及参与人员名单

### 2.3 办公费
- 办公用品:每月限额 200 元,主管审批
- 办公设备:需提交《资产采购申请》,IT 部门审批

## 3. 发票要求

### 3.1 发票类型
- 增值税专用发票(优先)
- 增值税普通发票
- 电子发票(需打印附后)

### 3.2 发票信息
- 抬头:XX 科技有限公司
- 税号:91110000XXXXXXXXXX
- 必须包含:开票日期、商品明细、金额、税率

### 3.3 发票时效
- 发票开具后 **90 天** 内必须报销
- 跨年发票截止次年 1 月 31 日

## 4. 资金转账政策

### 4.1 转账分级
| 金额 | 审批权限 |
| :-- | :-- |
| 1 万以下 | 财务专员 + 财务经理 |
| 1-10 万 | 财务经理 + 财务总监 |
| 10-50 万 | 财务总监 + 总经理 |
| 50 万以上 | 总经理 + 董事长 |

### 4.2 转账时效
- 普通转账:1-2 个工作日
- 紧急转账:当日完成(需附加急申请)
- 大额转账(≥ 10 万):需提前 1 个工作日申请

## 5. 借款政策

### 5.1 借款条件
- 因公出差或采购可申请借款
- 借款金额 ≤ 月薪 2 倍
- 借款需在 30 天内归还或报销冲抵

### 5.2 借款流程
1. 填写《借款单》
2. 主管审批
3. 财务审核
4. 出纳打款

## 6. 预算管理

### 6.1 部门预算
- 每年 12 月编制次年部门预算
- 预算执行情况每月汇总报告
- 预算超支需提交《预算调整申请》

### 6.2 预算审批
- 预算内支出:按标准流程
- 预算超支 10% 以内:部门负责人审批
- 预算超支 10% 以上:总经理审批
