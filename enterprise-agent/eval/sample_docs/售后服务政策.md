# 售后服务政策

## 1. 服务承诺

### 1.1 响应时间
| 故障级别 | 定义 | 标准版 | 企业版 | 旗舰版 |
| :-- | :-- | :-- | :-- | :-- |
| P0 | 系统不可用 | 4 小时 | 1 小时 | 15 分钟 |
| P1 | 核心功能受损 | 8 小时 | 2 小时 | 30 分钟 |
| P2 | 部分功能异常 | 1 工作日 | 4 小时 | 2 小时 |
| P3 | 咨询/建议 | 2 工作日 | 1 工作日 | 4 小时 |

### 1.2 服务渠道
- **标准版**:工单系统 + 邮件
- **企业版**:工单系统 + 邮件 + 专属客服群
- **旗舰版**:工单系统 + 邮件 + 专属客服 + 7×24 电话

### 1.3 服务时间
- 标准版:工作日 9:00-18:00
- 企业版:工作日 9:00-21:00
- 旗舰版:7×24 全天候

## 2. 故障处理流程

### 2.1 标准流程
1. 客户提交工单(描述问题 + 截图/日志)
2. 客服分诊(15 分钟内分级)
3. 技术团队排查(P0/P1 立即启动)
4. 修复并验证
5. 关闭工单 + 复盘报告(P0/P1 必须)

### 2.2 升级机制
- P0/P1:自动升级至技术负责人
- 30 分钟未响应:升级至客服经理
- 2 小时未解决:升级至技术总监
- 24 小时未解决:升级至 CTO

### 2.3 事后复盘
- P0/P1 故障需在 48 小时内提交复盘报告
- 报告含:故障原因、影响范围、处理过程、改进措施
- 改进措施需在约定时间内落地,客服跟踪验证

## 3. 退款政策

### 3.1 退款条件
| 版本 | 退款条件 | 退款比例 |
| :-- | :-- | :-- |
| 标准版 | 订阅 7 天内,未产生使用记录 | 全额退款 |
| 标准版 | 订阅 7 天内,有使用记录 | 退还 80% |
| 企业版 | 未开始实施 | 全额退款 |
| 企业版 | 实施中 | 按未完成比例退款 |
| 旗舰版 | 按合同约定 | 合同条款为准 |
| 定制开发 | 已交付部分 | 不退 |
| 定制开发 | 未开始部分 | 全额退款 |

### 3.2 退款流程
1. 客户提交退款申请(工单 + 说明原因)
2. 客服审核(3 个工作日内)
3. 财务核算退款金额
4. 财务总监审批(1 个工作日)
5. 出纳打款(3 个工作日内)
6. 关闭账号 + 数据归档

### 3.3 特殊情况
- 因产品质量导致退款:全额退款 + 书面致歉
- 因客户违约导致退款:扣除违约金后退还余额
- 争议情况:由客户成功总监介入协调

## 4. 投诉与建议

### 4.1 投诉渠道
- 客服热线:400-XXX-XXXX
- 投诉邮箱:complaint@example.com
- 工单系统:提交"投诉"类工单

### 4.2 投诉处理
- 24 小时内首次响应
- 3 个工作日内给出处理方案
- 7 个工作日内闭环
- 每月汇总投诉数据,管理层评审

### 4.3 建议奖励
- 被采纳的产品建议:赠送 1 个月延期
- 重大贡献建议:赠送 3 个月延期 + 公开致谢
- 年度最佳建议:免费升级一档版本(1 年)

## 5. 服务考核

### 5.1 SLA 指标
| 指标 | 目标 | 实际(2026 Q2) |
| :-- | :-- | :-- |
| 工单响应率 | ≥ 95% | 97.3% |
| 首次解决率 | ≥ 70% | 72.1% |
| P0/P1 恢复达标率 | ≥ 99% | 99.6% |
| 客户满意度 | ≥ 4.5/5 | 4.6/5 |

### 5.2 不达标补偿
- SLA 不达标:按合同约定退还月费 5%-20%
- P0 超时:额外赠送 1 个月延期
- 连续 3 月不达标:客户成功总监介入,协商解决方案
