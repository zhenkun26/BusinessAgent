# 产品手册

## 1. 产品版本

### 1.1 版本对比
| 版本 | 适用规模 | 价格(年) | 核心功能 |
| :-- | :-- | :-- | :-- |
| 标准版 | 20人以下 | 12,000 | 基础协作 + 文档管理 + 标准支持 |
| 企业版 | 50-200人 | 80,000 | 全功能 + API 接口 + 专属客服 |
| 旗舰版 | 200人以上 | 定制 | 企业版 + 私有部署 + 定制开发 |

### 1.2 模块清单
- **基础模块**(所有版本含):文档管理、任务协作、消息通知、权限管理
- **标准模块**(标准版以上):数据分析、报表导出、API 接口
- **高级模块**(企业版以上):工作流引擎、集成中心、审计日志、SSO 单点登录
- **定制模块**(旗舰版):私有化部署、定制开发、专属运维

## 3. 授权与订阅

### 3.1 授权方式
- 按**用户数**授权(50人/100人/不限)
- 订阅周期:1年/3年(3年享 8 折)
- 授权码通过邮件发放,管理员在后台激活

### 3.2 试用政策
- 免费试用 30 天(全功能)
- 试用限制:最多 5 用户,数据量 ≤ 1GB
- 试用到期后数据保留 30 天,需购买正式版恢复

### 3.3 升级与降级
- 升级:补差价,即时生效
- 降级:到期后生效,不退差价
- 模块增购:随时购买,按剩余周期折算

| :-- | :-- | :-- |
