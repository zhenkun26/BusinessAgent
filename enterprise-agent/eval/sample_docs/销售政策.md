# 销售政策

## 1. 客户跟进政策

### 1.1 新客户跟进
- 新客户首次接触后,销售人员需在 **24 小时内** 创建 CRM 跟进任务
- 首次跟进需在 **3 个工作日** 内完成
- 跟进结果必须记录到 CRM 系统

### 1.2 现有客户跟进
- A 类客户(年采购额 ≥ 100 万):每周至少跟进 1 次
- B 类客户(年采购额 10-100 万):每两周至少跟进 1 次
- C 类客户(年采购额 < 10 万):每月至少跟进 1 次

### 1.3 流失客户预警
- 客户连续 **30 天** 未跟进,系统自动标记为"流失风险"
- 流失风险客户需在 **5 个工作日** 内由销售经理介入

## 2. 折扣政策

### 2.1 折扣权限
| 折扣幅度 | 审批权限 |
| :-- | :-- |
| 5% 以下 | 销售人员自主决定 |
| 5%-10% | 销售经理审批 |
| 10%-15% | 销售总监审批 |
| 15% 以上 | 总经理审批 |

### 2.2 特殊折扣
- 战略客户可申请特殊折扣,需提交《特殊折扣申请单》
- 特殊折扣审批流程:销售人员 → 销售经理 → 销售总监 → 财务总监

## 3. 合同签署政策

### 3.1 合同金额分级
- 10 万以下:销售经理审批
- 10-50 万:销售总监审批
- 50 万以上:总经理审批 + 法务审核

### 3.2 合同模板
- 必须使用公司标准合同模板
- 非标准条款需经法务部审核
- 合同签署后 3 个工作日内归档

## 4. 佣金政策

### 4.1 佣金计算
- 基础佣金:合同金额的 2%
- 超额佣金:超额部分 5%(超额 = 实际销售额 - 目标销售额)
- 新客户首单:额外 1% 奖励

### 4.2 佣金发放
- 按季度发放
- 合同回款率需达到 80% 以上才可发放
- 离职员工佣金按比例发放(按在职天数)

## 5. 客户等级评定

### 5.1 等级标准
| 等级 | 年采购额 | 跟进频率 | 折扣权限 |
| :-- | :-- | :-- | :-- |
| VIP | ≥ 200 万 | 每周 | 15% |
| A | 100-200 万 | 每周 | 10% |
| B | 10-100 万 | 每两周 | 5% |
| C | < 10 万 | 每月 | 3% |

### 5.2 等级调整
- 每季度初根据上季度采购额重新评定
- 连续两个季度不达标,等级下调
- 战略客户等级由销售总监指定

## 6. 超期使用政策

### 6.1 软件产品超期
- 软件订阅超期 30 天内:功能限制,数据保留
- 超期 30-90 天:服务暂停,数据保留 6 个月
- 超期 90 天以上:服务终止,数据归档后清理

### 6.2 超期处理流程
1. 系统自动发送超期提醒(到期前 7 天、3 天、1 天)
2. 超期后客服介入,联系客户续费
3. 超期 30 天升级为紧急工单,由客户成功经理跟进
4. 超期 90 天由法务介入,启动合同终止流程
