  before shared access, 409 for a busy session, 503 when coordination is unavailable.
  Owner failure is an error, distinct from a user-requested cancellation. No rollback.

  validation; cross-worker callbacks supported in code, without memory fallback.
- Per-invocation PostgreSQL prompt snapshots in ContextVar; activation/rollback/traffic
  changes affect subsequent requests on any worker, while running requests stay pinned.
  Failed DB reads stop graph/model work instead of serving an old cached template.
