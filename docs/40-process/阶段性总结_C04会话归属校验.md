## Changes and policy

The [session ownership contract](../50-engineering/session-ownership.md) defines
the five-endpoint role matrix, compatibility changes, errors and live checklist.

- Added [shared ownership/preparation helpers](../../enterprise-agent/app/security/session_access.py).
  Queries use bound values and persisted `sessions.user_id`, not ID prefixes or
  checkpoint existence. Missing/foreign/invalid IDs return the same fixed 404;
  ownership-store failures return a fixed 503 and cannot fall back to checkpoint
  state or continue to graph work.
- [Message and stream](../../enterprise-agent/app/api/chat.py) authorize and prepare
  the session before graph imports, audit, task registration or StreamingResponse.
  Existing-row updates repeat the owner predicate and check RETURNING. New rows
  require omitted/null IDs, use opaque bounded server IDs and never upsert over an
  ID collision. Explicit unknown IDs no longer create sessions.
- History checks ownership before obtaining the checkpointer; checkpoint-miss
  fallback uses only previously authorized status. Feedback no longer creates a
  placeholder session; it holds a shared row lock while recording feedback and
  optional draft in the request transaction.
- Ordinary message, stream, history and feedback are owner-only for every role.
  Only cancel preserves the existing owner-or-admin exception. Manager/department
  membership does not grant access. Administrator cancellation still uses the
  process-local registry; distributed cancellation is not implemented here.
- Updated OpenSpec proposal/design/session-ownership delta/tasks, backend README,
  safety-review table, ROADMAP/ISSUES/baseline, indexes and current context. Only
  task 2.1.1 is complete; 2.1/2.1.2 remain unchecked. No main-spec sync or archive.
