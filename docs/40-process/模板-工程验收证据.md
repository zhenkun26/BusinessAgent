# 工程验收证据模板

> 模板不代表已执行。复制到对应 C 项的交付记录，未执行的字段写明原因，不填模拟人员、时间或结果。

## 范围与版本

- C 项 / 子任务：
- 本轮用户授权、明确排除项：
- 验收条款链接（ISSUES / delta）：
- 代码提交 / 工作区内容是否修改 / 相关源码 SHA-256：
- 镜像摘要（本项不用镜像则 NOT_APPLICABLE，并说明）：
- 执行时间及时区：
- 系统/硬件、Python/依赖版本、模型标识：
- 输入数据集/配置摘要与哈希（不含凭证）：
- 角色/命名空间与环境隔离说明：

## 检查与结果

| 验收条款 | 证据等级 E0–E4 | 命令或人工步骤 | 预期结果 | 实际结果 / 退出码 | PASS / FAIL / BLOCKED / NOT_APPLICABLE | 证据路径 |
| --- | --- | --- | --- | --- | --- | --- |
| 待填写 | 待填写 | 待填写 | 待填写 | 未执行 | BLOCKED（补原因） | 无 |

- 检查程序完成状态与业务准备度分别记录；BLOCKED 不因 exit 0 或计划结构通过而转 PASS。
- 人工浏览器验收单列操作人、浏览器版本、角色、步骤与实际观察；尚未执行如实标记。
- 不保存 token、口令、原始请求/响应、个人数据、环境变量转储或含这些内容的异常堆栈。

## 保留资产与安全边界

- 新建文件/目录、任务/参考业务数据的副作用：
- 运行前后既有文件/输入哈希是否一致：
- 保留资产路径（用户如需清理由用户操作；无自动删除）：
- 脱敏与覆盖/符号链接防护检查结果：
- 未使用的危险脚本/清理路径及原因：

## 结论与复验

- 本子任务完成 / 未完成；整个 C 项状态：
- 未覆盖的接口、环境、并发、恢复或人工流程：
- FAIL/BLOCKED 原因与修复/补资源后的复验条件：
- 后续改动会使哪些证据失效：
- `formal_uat=false`、`release_evidence=false`、`release_allowed=false`（工程/参考环境证据保持此边界）：
- 本轮提交与推送状态、下一项暂停点：
