## Remaining gaps and stopping point

D01–D16 are all BLOCKED. Actual source quiescence and clean exit, complete physical
restoration, semantic PG counts/content, collection load/real retrieval, restored identity/
expiry/replay behavior, external-effect reconciliation and measured RTO <=1h/RPO <=24h
are not verified. No schedule is installed. A proposed cadence is not an achieved RPO.
Byte restore and an operator timestamp report never imply application acceptance.

This candidate deliberately requires stopped same-version local named volumes; no hot
backup/PITR/HA/tablespaces/ACL/xattr or cross-version recovery guarantee. Exact images,
configuration and secret versions need separate custody. Backups include private data;
encrypted storage and independent copy are prerequisites, not delivered encryption features.
Process shutdown itself can trigger database/Docker file lifecycle; real non-deletion
compliance still requires D16 review. External operators can race observations; no fencing
of host writers or C10 lease-expiry writes is claimed. Failed/uncertain helpers and restored
volumes remain retained, and later attempts need fresh destinations.

O01–O16, B01–B16, S01–S16, R01–R20, real runtime/full RAG and historical credentials
remain BLOCKED. C10 stays open. `formal_uat=false`, `release_evidence=false` and
`release_allowed=false` are unchanged. Stop after the local C22 commit; wait for user
