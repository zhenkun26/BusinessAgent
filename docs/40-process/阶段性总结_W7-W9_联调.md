## 五、新增关键经验

1. **LangGraph reducer 与 checkpoint 的交互:** 带 `operator.add` 的列表字段在断点恢复后会残留上一轮数据,需要「可重置」reducer(初始状态传空列表即重置);且 checkpoint JSON 反序列化会把 pydantic 模型变成 dict,消费方必须做防御转换
2. **SQLAlchemy 2.x:** 所有原生 SQL 必须 `text()` 包装,`conn.execute("...")` 直接报错
3. **PostgreSQL JSONB:** `= ANY(jsonb_col)` 非法,数组成员判断用 `jsonb_col ? 'value'` 或 `@>`
4. **Mock 优先策略再次验证:** 工具层 Mock 实现让 RBAC/Saga/审批链路在真实业务系统缺位时仍可完整联调
5. **降级链会掩盖配置错误:** memory 后端 + 关键词降级让「向量检索未生效」长期不可见,联调必须核对日志中的后端标识
