# Record verified upstream notices

## Why
The source-rights audit now links twelve generated tooling instructions to the official OpenSpec 1.7.0 package and 89 font files to byte-identical current official distribution. Header-only declarations and an absent font license text should not substitute for retaining the upstream notices.

## Scope
Add the exact verified OpenSpec MIT text, applicable OFL 1.1 text and embedded font copyrights, plus public path/hash/source evidence. Record the other 128 font files as unresolved version/distribution evidence rather than clearing them. Update the existing third-party notice index.

## Non-goals
No rights-state transition, verifier relaxation, inventory/count edits, source replacement/removal, relicensing, permission invention, original C17 corpus upload, commit, push, merge or deployment. No claim that all 457 rights or final-image notices are cleared.
