# Case index

Start with a brief. Historical review and source ledgers contain spoilers and are opened only under the [coaching protocol](../workflow/coaching.md). Case authoring itself was not a learner session. The subsequently completed BA-01 and EXT-01 conversations are preserved separately in the [learning records](../runs/README.md); do not preload their answers for a new exercise.

| ID | Brief | Core learning | Evidence boundary |
| --- | --- | --- | --- |
| BA-01 | [Model routing](businessagent/model-routing/brief.md) | Define the decision, compare explanations, design distinguishing tests, revise by task | Retrospective BusinessAgent documents; historical performance reports, not fresh benchmarks |
| EXT-01 | [Process depth and delivery checks](external/process-sizing/brief.md) | Right-size a process, identify a check's blind spot, preserve decision changes | Public upstream plan and handover; author-reported implementation, fictional customer examples |

Each case contains `brief.md` (initial learner packet), `review.md` (staged facilitator guide and outcome), and `sources.md` (versioned provenance). Do not preload an entire case folder for a learner session.

BA-01 mainly studies an early contributor's reasoning. EXT-01 broadens the comparison beyond BusinessAgent. Neither case proves the learner made the historical decisions. Synthetic transfer prompts inside the cases are exercises, not a third historical case.

Additional cases should have an identifiable decision, alternatives or constraints, evidence that changed the choice, and a traceable result or explicit result gap. A polished README alone is insufficient to reconstruct a real decision history.
