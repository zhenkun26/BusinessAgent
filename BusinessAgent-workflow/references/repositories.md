## What changes this design

The user's learner-first requirement and actual case evidence are the primary design inputs. Upstream workflows are references, not mandatory pipelines. If an exercise becomes repetitive, simplify the interaction and record what coverage was dropped. If lessons are never reused, improve retrieval and relevance before adding more documentation or agents.
